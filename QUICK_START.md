# NCS Launcher - Quick Start (GitHub Build)

## The Easiest Way: Build on GitHub (Free!)

### 3 Simple Steps:

1. **Create GitHub Account**
   - Go to https://github.com
   - Sign up (free)

2. **Upload This Project**
   - Create new repository
   - Upload all files from this folder
   - GitHub automatically builds your APK!

3. **Download & Install**
   - Go to Actions tab
   - Download the APK
   - Install on your S23
